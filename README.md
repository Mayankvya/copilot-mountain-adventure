# Mountain Dusk

A small, data-driven choose-your-own-adventure game about finding your way
down a mountain at dusk. It uses only the Python standard library.

Run it with:

```text
python adventure.py
```

Use `--seed` to make the ridge weather event repeatable:

```text
python adventure.py --seed 42
```

Run the test suite with:

```text
python -m unittest
```
